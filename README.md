# Tax-calculator-project

-Project Overview
The tax calculator is a programming project 
designed to calculate estimated tax based on user's income applicable tax rates

-Features
calculate estimated tax based on income
display the calculated tax income
calculate income after tax
accepted user input
provide clear and easy to understand results

-Technologies
Python

-How to run
clone or download this repository
install python on your computer
open the project in visual studio code
run the python file
enter your income when prompted to calculate your estimated tax
